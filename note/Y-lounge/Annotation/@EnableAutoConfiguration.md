#Annotation 

프로젝트에 추가된 라이브러리(jar)를 보고 알아서 추측해서 설정해주는 기능 

### 작동
이 Annotaion은 프로젝트의 build.gradle (또는 xml)에 있는 **의존성을 추적**함.

- **상황1: spring-boot-starter-web이 있다.**
	-> **판단**: "웹 개발을 하려나보네?" 톰캣 서버 띄우고, 스프링 MVC 설정 해줘야지
- **상황2: h2 데이터베이스 라이브러리가 있네?**
	-> **판단**: DB 연결해야겠네? 근데 DB 주소 설정이 없네? 그럼 내가 메모리 DB로 연결해줘야지

과거에는 의존성도 추가하고, 설정도 알아서 했어야 했지만, 의존성 추가만 하면 설정도 알아서 해줌!
