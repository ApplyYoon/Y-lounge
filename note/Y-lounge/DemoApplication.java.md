Spring Boot 애플리케이션의 [[Entry Point]]

- **@SpringBootApplication** 
	- 설정 자동화([[@EnableAutoConfiguration]])
	- 컴포넌트 스캔([[@ComponentScan]])
	- 설정 등록([[@Configuration]])

- Main Method
	- 자바 프로그램의 시작 버튼.
	- SpringApplication.run 명령어가 실행되면서
	  [[Spring Container]]를 만들고 서버를 킴.


즉 해당 파일이 실행되어야 서버가 켜지고 웹 사이트가 작동함.
